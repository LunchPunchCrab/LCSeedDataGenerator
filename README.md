# DataGenerator

This is a c# program that simulates key parts of Lethal Company's seed generation code for all 99,999,999 possible seed values. 
The information is then stored by writing it to a compressed .bin.zst file for each of the (current as of v81) 11 moons.

These files are used for an adjacent project, a Lethal Company Website (listed on the Github About page), by populating a PostgreSQL database.

This is my first coding project of this kind, so expect messy code.

Please let me know if there are any issues, mainly inaccuracies, with generating the LC seed data.
